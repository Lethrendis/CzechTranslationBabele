
# CzechBabele

Czech translation of Babele version 2.7.5

## Popis
Tento modul poskytuje českou lokalizaci pro Babele verze 2.7.5. Obsahuje překlady základních textů aplikace.

## Instalace
Pro instalaci modulu obvyklým způsobem můžeš použít následující odkaz ve Foundry VTT:

```
https://raw.githubusercontent.com/Lethrendis/CzechTranslationBabele/main/module.json
```
